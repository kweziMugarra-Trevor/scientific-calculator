# Scientific Calculator

A modern scientific calculator built with HTML, CSS, and JavaScript. It runs directly in the browser and includes common scientific functions such as trigonometry, logarithms, exponentials, square roots, factorials, and memory operations.

## Features

- Basic arithmetic operations
- Scientific functions:
  - sin, cos, tan
  - inverse trig functions
  - sinh, cosh, tanh
  - log, ln
  - sqrt, cbrt
  - exp
  - abs
  - factorial
- Degree and radian mode
- Memory operations:
  - MC
  - MR
  - M+
  - M-
- Calculation history
- Responsive layout for desktop and mobile
- Keyboard input support

## Demo

Open the app in your browser by loading `index.html` locally, or deploy it with GitHub Pages.
